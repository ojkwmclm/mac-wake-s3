## 连接与权限

官方 HTTPS 认证 → WSS 1886 /mqtt → 订阅设备 r 主题 → 校验绑定账号来源 → 复用已验证 USB 唤醒队列。

不新增任意键盘输入、密码输入、开机键控制或自动登录。默认只发 USB Remote Wakeup。状态返回 `mac_online: null`，不把 USB 总线状态冒充 Mac 在线。
