# v0.4 睡眠按钮

目标：新增点灯 APP `sleep` 按钮，保留 `btn` 唤醒和用户设置的按钮名称。

实现：独立媒体控制 HID 接口，配合既有键盘接口模拟 Option＋Command＋媒体推出键。没有增加任意文本输入、自动登录或远程脚本。共用单请求队列与 3 秒间隔，拒绝同一消息混合 sleep/btn。校验绑定账号，忽略保留或带重复标志的消息。睡眠只接受 tap/press。

解析边界测试 23 项通过。v0.4 已写入开发板并通过 Flash 数据哈希校验。用户已按步骤点击“睡眠”，等待后点击“唤醒mac”，并明确确认“睡眠、唤醒及远程桌面均正常”。v0.4 本次端到端实机验收通过。隔夜睡眠、断网及掉电恢复尚未验收。

官方依据：https://support.apple.com/en-us/102650

## 数据键名调整

按用户要求，当前固件只使用 `btn-sleep`（睡眠）与 `btn-wakeup`（唤醒）。原 `sleep` / `btn` 不再触发。显示名称仍由 APP 设置，不受固件回传覆盖。键名调整后解析测试通过，更新烧录并校验后，用户明确确认“两个按钮和远程桌面均正常”。新键名版实机回归通过。
