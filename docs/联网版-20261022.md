# 联网版 v0.2 · 2026-10-22

用户报告按钮验证成功后，已通过本机输入窗口完成 Wi-Fi 配置，凭据与联网固件只保存在私有 work 目录，未放入分享包。

已完成：保持既有 USB 唤醒逻辑；新增 mDNS 固定访问名称 mac-wake-s3.local；实际联网配置下编译、链接、分区检查通过；联网应用大小 782,144 字节，1MB 应用分区剩余约 25%；合并镜像与 bootloader、分区表、应用按偏移逐字节一致。

后续实测：联网固件已烧录，写入哈希校验通过；用户复位后 USB 再次识别为 Mac Wake S3；Wi-Fi 已连接，mDNS 与 HTTP 页面可访问。接口测试：页面 HTTP 200；错误口令 HTTP 401 且不产生请求；正确口令 HTTP 202；在 Mac 清醒时板端结果为 host_bus_active，未冒充实际唤醒成功。随机控制口令已由用户在本机窗口选择复制到本机剪贴板，未输出到聊天。
