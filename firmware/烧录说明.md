# 按钮测试镜像

`mac-wake-s3-button-v0.1.bin` 是合并镜像，包含 bootloader、分区表和应用，烧录起始地址 **0x0**。目标仅为 ESP32-S3、16 MB Flash 的开发板。

此镜像：

- Wi-Fi 未配置，手机页面不可用。
- 不发送按键，只请求 USB Remote Wakeup。
- 正常启动后，短按 BOOT 触发一次请求。
- 已通过编译及镜像格式检查，未烧录、未实测唤醒。

使用 ESP-IDF 环境内的 esptool，替换 `实际串口` 后，在工程根目录执行：

```sh
python -m esptool --chip esp32s3 --port 实际串口 --baud 460800 write_flash --flash_mode dio --flash_freq 80m --flash_size 16MB 0x0 firmware/mac-wake-s3-button-v0.1.bin
```

该操作会替换板上应用及分区表。如果板上已有需要保留的固件，先备份。无需额外执行全片擦除。烧录完成后，原生 USB 接口应连接到 Mac 作为 HID 键盘；串口日志需走开发板独立的 USB 转串口接口 / UART0。

若无法连接下载器，按住 BOOT，短按 RESET，再松开 BOOT，进入下载模式；完成后正常复位。测试唤醒时只短按 BOOT，不按 RESET。

若要启用手机控制，按 README 配置 Wi-Fi 和控制口令并重新构建；不能通过修改此二进制文件填写配置。
